# Установка

```
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

# Получение ключей

> Обязательные условия:
>
> - в устройстве должно быть настроено wifi соединение через официальное приложение
> - компьютер и устройство должны быть в одной локальной сети или как минимум чтобы между сетями работал mDNS

Необходимо перевести устройство в режим сопряжения, путем удерживания кнопки на 5 сек, и подключиться к его wi-fi сети: WFN-02 или типа того.

Запустить скрипт получения токена:

```
python get_data.py
```

> Если скрипт соединяется с устройством, но не может получить токен, то нужно повторить упражнение с удержанием кнопки на 5 сек не отключаясь от wi-fi устройства.
> А лучше сразу сделать так: перевести в режим сопряжения, подключиться к wifi устройства и еще раз перевести в режим сопряжения и после этого запустить скрипт.

После того как скрипт получит токен, не прерывая его исполнения переподключите компьютер к домашней сети и продолжите выполнение скрипта. По окончании выполнения скрипт выведет в консоль `json` с параметрами и токенами устройства, сохраните `json` в файл (например `data.json`) и положите в папку со скриптами.

# Отправка параметров MQTT

Скрипт сырой и пока не берет mac из json-файла, поэтому его нужно прописать в команду запуска.

```
python set_mqtt.py \
  --keys data.json \
  --mac "00:00:00:00:00:00" \
  --host "192.168.1.50" \
  --port 1883 \
  --user "mqtt" \
  --password "mqtt"
```

## Параметры скрипта

### Обязательные

- `--keys` имя json файла
- `--mac` mac адрес устройства, возьмите из json из поля `macaddr`
- `--host` адрес mqtt сервера

### Необязательные

- `--port` порт mqtt
- `--user` логин пользователя mqtt
- `--password` пароль пользователя mqtt
- `--secure` True если mqtt использует tls. При указании этого флага нужно указать `--port`, потому что по умолчанию будет 1883, а не 8883
